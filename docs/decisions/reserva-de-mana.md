# Reserva de mana

O usuário pediu uma reserva visível abaixo do exílio, seguindo a imagem fornecida.
Depois de apresentadas as alternativas, aprovou automatizar terrenos básicos e
selecionar manualmente a mana nos demais casos. Todos os jogadores veem as reservas.
O jogador pode zerar a reserva e desvirar os terrenos; ao passar o turno a reserva
é zerada sem desvirá-los. A implementação está descrita na
[issue local](../issues/reserva-de-mana.md).

Após testar, o usuário pediu que o painel aberto para escolher a mana de uma
exceção feche automaticamente após a escolha. O painel aberto manualmente
continua disponível para ajustes até ser fechado.
